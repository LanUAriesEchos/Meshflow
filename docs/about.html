01 / What

What is Meshflow

One keyboard and mouse, seamless across every machine on your desk.

Meshflow lets one keyboard and mouse control multiple computers on the same local network. The cursor moves from one screen to the next as if the machines were a single desktop. Clipboard sharing and TLS encryption are built in, so your input data stays private on the wire.

Meshflow runs as a server on your primary machine and as a client on each secondary machine, communicating over your existing LAN. No special hardware, no cloud services, no accounts.

03 / How it works

How it works

Server, clients, and your existing LAN. No cloud, no accounts.

1

Server

Your primary machine runs the Meshflow server. It captures keyboard and mouse input and forwards it to whichever screen the cursor is currently on.

2

Clients

Each secondary machine runs an Meshflow client. Clients connect to the server over your LAN, receive input events, and inject them locally.

3

TLS channel

All traffic between server and clients is encrypted with TLS. Meshflow generates and manages certificates automatically on first run.

The server tracks cursor position across all configured screens. When the cursor crosses an edge, input is redirected to the appropriate client. Clipboard content travels with the cursor. Everything happens over your existing local network, no internet required.

07 / Roadmap

Roadmap

From input sharing to a unified distributed workspace. One workspace, many computers, distributed by design.

Meshflow is not just another keyboard and mouse sharing app. The long-term vision is a Unified Distributed Workspace: multiple computers remain independent systems but cooperate as one user-facing workspace. Each device contributes its own CPU, GPU, memory, storage, display, and input while Meshflow provides the coordination layer that makes the collection feel coherent. Workload stays distributed. No machine is reduced to a passive display endpoint.

Shipped - v1.0

Phase 1: Core foundation

Keyboard, mouse, and clipboard sharing across Windows and Linux with TLS encryption.

Shipped - v1.1

Phase 1: Workspace polish

File transfer, LAN auto-discovery, redesigned UI, themes, and a branded installer.

Planned - v1.2

Meshflow Port Share

Share localhost ports between machines. Your dev server at :3000, reachable on every connected PC.

Planned - v1.2 to v1.4

Phase 1: Strengthen the foundation

Smoother networking, richer clipboard, better onboarding, and more platforms.

Planned - v1.2

Phase 2: Meshflow Display

Turn a second machine into a real extended display, not just a remote window.

Planned - v2.x

Screen Watch

View a peer's screen in a window. Opt-in, visible indicator, fully logged.

Future - v2.0

Phase 3: Hybrid Workspace

Input sharing plus displays in one workspace, with drag and drop, audio, and a mobile companion.

Research

Phase 4: Remote Application Research
