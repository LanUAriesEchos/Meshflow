Built for distributed workflows

Each machine keeps its own compute power. Meshflow handles the coordination.

One keyboard, every machine

Drag the cursor off one screen and onto another without pressing any buttons. Meshflow tracks edge positions so the transition feels instant and natural. No KVM switch, no cable swapping.

Shared clipboard

Copy and paste text and images between systems automatically. Your clipboard content travels with the cursor as it crosses screen boundaries. No file sharing, no cloud sync.

TLS encrypted

Server and client traffic is encrypted with TLS to keep your input data private. Meshflow generates and manages certificates for you automatically. Nothing leaves your local network.

Cross-platform

Windows, macOS, and Linux. X11 and Wayland are both supported on Linux, so Meshflow works across mixed-OS setups without compromise.

Synergy and Barrier compatible

Works with the Synergy and Barrier wire protocols for broad interoperability. Connect Meshflow to existing Synergy or Barrier clients and servers without replacing everything at once.

Each machine stays useful

Unlike remote desktop tools that centralize everything on one machine, Meshflow keeps each computer independent. Your laptop runs its own apps. Your desktop runs its own apps. Meshflow just connects them.

How it works

Meshflow runs as a server on your primary machine and as a client on each secondary machine.

Real desks, real workflows

Meshflow is not just for switching between machines. It is for people who use several computers at once.

The developer desk

A powerful desktop runs Docker, AI inference, and build jobs. A laptop handles the browser, Slack, and email. Meshflow lets you move between them with one keyboard and paste code snippets from the laptop straight into the desktop terminal. Each machine does what it is best at. No remote desktop, no rendering overhead.

The multi-OS workstation

A Windows gaming PC, a Linux dev box, and a Mac for design work. Meshflow connects all three over your LAN with native input capture on each platform. Move the cursor from a Windows game to a Linux terminal to a Mac design tool without touching a KVM switch.

The home server setup

A desktop for daily work, a headless home server running background services, and a laptop on the couch. Meshflow reaches all of them. Check on a build, paste a config change, and jump back to the laptop without leaving your seat.

The mixed-environment tester

Test your app on Windows, Linux, and macOS at the same time. Copy a URL from your main machine and paste it into a browser on each test machine. Meshflow keeps the clipboard in sync across all of them, so cross-platform testing stops being a context-switching chore.

Frequently asked questions

Everything you need to know before getting started.

Yes. Meshflow is 100% free and open source under GPL-2.0 with an OpenSSL exception. No subscriptions, no paid tiers, no feature locks. The source code is available on GitHub for anyone to audit, modify, and contribute to.
No hardware needed. Meshflow is software-only and works over your existing local network. Just install it on each machine, connect them, and you're ready. No KVM switch, no extra cables, no cloud account.
All traffic between Meshflow server and clients is encrypted with TLS. Meshflow generates and manages certificates automatically, and supports fingerprint-based peer verification so you can confirm you're connecting to the right machine. Nothing leaves your local network.
Yes. Meshflow is built on the Synergy codebase and uses the same wire protocol. It works with existing Synergy and Barrier clients and servers, so you can mix Meshflow into your current setup without replacing everything at once.
Yes. On Linux, Meshflow supports both X11 and Wayland. The correct backend is selected automatically based on your session type, so it works regardless of which display server you're running.
There's no hard limit. One machine acts as the server (with the shared keyboard and mouse), and you can connect as many client machines as your network can handle. Arrange them in the GUI grid to match your physical desk layout.
