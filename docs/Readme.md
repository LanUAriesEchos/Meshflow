# Meshflow

Meshflow is a free and open-source keyboard and mouse sharing app. Use the keyboard, mouse, or trackpad of one computer to control nearby computers and work seamlessly between them.

- [Homepage](https://RimoraStudio.github.io/Aether)
- [Code](https://github.com/RimoraStudio/Aether)

Meshflow is an open-source keyboard and mouse sharing utility for Windows, macOS, and Linux.
