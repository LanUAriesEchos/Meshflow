# Security Policy

## Supported Versions

The latest minor release of Meshflow is supported and receives security updates when available. Releases are published on GitHub:

https://github.com/RimoraStudio/Aether/releases

## Reporting a Vulnerability

Please report vulnerabilities on the Meshflow issue tracker as bugs:

https://github.com/RimoraStudio/Aether/issues

Include steps to reproduce the issue and, if possible, the affected component or source file. Do not publicly disclose security issues before they have been reviewed and addressed.
